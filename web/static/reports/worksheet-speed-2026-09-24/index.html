One run per worksheet and model. Luna used low reasoning for screenshot reading and high for report writing. Sol used its default reasoning setting. These times show the actual configured workflows, not a controlled model-only test.

What affects the wait

  • RadSpeed sends the screenshot to a vision model to read marks, table positions and measurements. This took 4–8 seconds here.
  • RadSpeed then sends those source notes to a report model. This took another 7–11 seconds. The calls run in sequence.
  • The separate “Transcribe indication” button uses local text recognition in the browser. A clear synthetic indication took about 0.3 seconds after the browser loaded its worker. This is a different path.
Accuracy matters: Luna read “BPD” as “BP” in the obstetric worksheet. Sol missed the note “Repeat imaging recommended.” Both draft reports need clinical review.

Faster routes to test

  • One vision call: ask Luna to return both structured source notes and the draft report in one response. This removes one model call, while keeping the source notes visible for review.
  • Direct text from the source system: if the original worksheet offers selectable text or an export, use that text and format it in one model call. Check that selected boxes and table labels come through.
  • Local text reading plus one report call: this could avoid the vision request on simple typed notes. On these clear worksheet images, the current local reader missed renal measurements and flattened selected and unselected boxes. It also lost obstetric biometry. It is not safe as the only reader for these forms.
  • Structured local reading plus one report call: use positions and box detection with local text reading, then send structured findings to Luna. This needs a layout-specific quality check before use.
  • Keep two calls but use a faster reading model: Luna low already reduced the reading step to 4–5 seconds. Any further model change needs accuracy tests against laterality, measurements and marked choices.

Recommended next experiment: compare a one-call Luna report with the current two-call workflow on a wider synthetic worksheet set. Keep the faster route only if it preserves every marked finding and measurement.
